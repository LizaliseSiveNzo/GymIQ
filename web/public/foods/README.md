# Food images

Drop the food images you generate here. They are served at `/foods/...` by the web app
(same pattern as the exercise images in `/web/public/exercises/`).

**Filename = the food's ID + `.webp`** (`.jpg` and `.png` also work). The table below maps
every food in the catalogue to its exact filename. If a food has no image yet, the app
simply shows text only — nothing breaks.
